# Архив доступных результатов

Сюда скопированы прежние сборки, ZIP исходников, снимки экрана, видео и страницы резервного копирования из рабочей среды. Копии сохранены 4 ноября 2026. Файлы со старыми номерами — исторические; текущий код находится в корне и src/.

Страницы save-game-backup.html и game-backup-original.html сохраняются как результаты прошлой работы. Интерфейс чата показывал их кодом и сообщал об ошибках скачивания. Это не основной рекомендуемый способ восстановления; используйте текущие исходники, Git или сохранённый ZIP.

Полная папка восстановления из прежней среды отдельно не дублируется: её содержимое уже сохранено в tuman-i-kosti-recovery-2026-11-03.zip. Заголовки ZIP позволяют восстановить источники соответствующих версий. Личные сохранения партий сюда не добавлены.
