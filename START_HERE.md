# Начните отсюда — «Туман и кости», 0.8.4

Состояние на 5 ноября 2026, Москва. Репозиторий предназначен для продолжения работы другим чатом ChatGPT/Codex и для восстановления проекта.

## Что открыть

- `index.html` — автономная кампания. Открывается в браузере без установки и сети.
- `battle-lab.html` — отдельный новый боевой эксперимент 4×4. Также доступен кнопкой «Пробный бой» в кампании.
- `README.md` — устройство проекта, изменения версий, сборка и тесты.
- `AGREED_RULES.md` — решения пользователя. Более поздние уточнения имеют приоритет.
- `BATTLE_EXPERIMENT.md` — точные текущие правила пробы, возможности и ограничения инженера.
- `ROADMAP.md` — этапы и приоритеты. Оценки предварительные, календарный план ещё не согласован.
- `PROJECT_CONTEXT.md` — контекст переписки и открытые задачи.
- `ENVIRONMENT_INCIDENT_2026-11-03.md` — подтверждённые наблюдения о недоступности среды и скачивании файлов.
- `reference/` — пользовательские RAR и DOCX.
- `archive/` — сохранённые прежние HTML, исходники ZIP, скриншоты, видео и страницы резервного копирования. Это история доступных файлов, не восстановленная история Git-коммитов.

## Самое важное различие

Кампания и боевая проба пока используют разные правила боя. Перенос новой системы в кампанию НЕ выполнен. Не объявляйте его завершённым и не заменяйте старую систему без учёта результатов проб пользователя.

Последние изменения пробы: 3 клетки за 1 ОД с сохранением оплаченных шагов, карта 16×10, три типа защиты с формулой R/(R+50), радиусы дальних действий, обязательные действия или явный пропуск, инженер и подклассы Бронник / Подрывник / Фортификатор.

В 0.8.4 добавлен четвёртый сценарий «Перехват пленника»: новая цель без обязательного уничтожения охраны. Повторные атаки сохранены.

Ранее добавлены блокировка дальних атак соседним врагом, уворот плута/следопыта, барьер послушника, фигуры героев и редактор рельефа с переносимыми макетами.

В пробе уже действуют силовая броня, мины, укреплённые укрытия и мостки. Ремесло Бронника, улучшения и мосты Фортификатора на глобальной карте, дополнительные ловушки и найм инженера в кампании ещё предстоят.

## Сборка и проверка

```sh
python tools/build.py
python tools/verify_backup.py
```

Сборка не требует внешних библиотек. Источники: `template.html`, `src/`, `assets/`. `index.html` и `battle-lab.html` генерируются: правки вносить в источники и пересобирать.

Браузерные тесты требуют Python Playwright и Chromium; путь задаётся переменной `CHROMIUM_PATH`, по умолчанию `/usr/bin/chromium`.

```sh
python tests/test_game.py
python tests/test_development.py
python tests/test_battle_lab.py
python tests/test_battle_editor.py
python tests/test_convoy.py
```

На версии 0.8.4 эти пять наборов проверяют: 19 + 16 + 18 + 12 + 14 = 79 сценариев. В наборе боевой пробы дополнительно выполняется 12 автопартий: три сценария для четырёх вариантов инженера. Это не доказательство игрового баланса. Остальные наборы в `tests/` проверяют анимации, отрисовку, тактику, отношения и бестиарий.

Проверка SHA-256 относится к зафиксированному снимку; после намеренных изменений файлов манифест нужно обновить. Самостоятельное пересоздание `index.html` проверяйте до обновления манифеста.

## Сохранность

Не удалять архивы и пользовательские материалы ради очистки. Не использовать force-push для сохранения очередной версии. Перед отправкой новой версии проверять удалённые ветки и чужие изменения. Изменение проекта в рабочей среде само по себе не означает, что оно попало в GitHub.

Сохранение партии (JSON через «Экспорт») и исходники игры — разные вещи. Личные партии пользователя в этом репозитории отсутствуют. Полный сырой экспорт чата здесь не представлен: документы содержат сводку известных решений, ограничений и истории работы.
