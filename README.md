## Новое в 0.8.2

Пробный бой: карта 16×10, три клетки за 1 ОД с сохранением оплаченного остатка, отдельные колющий/режущий/магический рейтинги и процентное снижение с убывающей эффективностью. Добавлены подсветка дальности и линии огня, масштаб карты, запрет завершения хода до выполнения или явного пропуска остатка действий. Инженер занимает одно из четырёх мест; доступны базовый вариант и согласованные Бронник, Подрывник, Фортификатор. Боевые способности работают: силовая броня, мины, укреплённые укрытия и мостки. Инженер ещё не добавлен в кампанию; его ремесло и работы на глобальной карте — следующие задачи. Подробности: [BATTLE_EXPERIMENT.md](BATTLE_EXPERIMENT.md).

## Новое в 0.8

Реализована новая ветка города из обсуждения с братом: Кузня, Библиотека, Плац, Академия, Лаборатория, Башня мага, Магическая кузница, Библиотека зачарований, Магическая академия, Алхимическая лаборатория, Место силы, Храм и Капище. Стрельбище и Слесарная мастерская используют прежние идентификаторы range и den, сохраняя свои ветки подклассов. Академия оставлена необязательной: окончательного решения об удалении не было.

Требование здания в городе отделено от замены на том же гексе и от соседской синергии. Магическая кузница ставится поверх Кузни, Библиотека зачарований — поверх Библиотеки, Алхимическая лаборатория — поверх Лаборатории. Предшественник остаётся в цепочке эффектов и удовлетворяет требованиям. Храм и Капище взаимно исключают новую постройку другой ветки. Верховный храм поверх Храма открывает прежние продвинутые подклассы по уровню. Храм восстановления остаётся общей независимой веткой воскрешения. Старые магические постройки сохранены в данных и показываются в меню, если уже присутствуют; старые обученные герои не теряют способностей. Прежняя Кузница мастерской названа «Военная кузница» и сохраняет производство и военные ветки.

**Знания и исследования.** Базовый доход 2 знания за ход; Библиотека +4, Академия +3, Лаборатория +2. В Башне нужен живой послушник в городе. Знания расходуются при начале исследования; работа длится 2–3 начала хода. Уход исследователя или утрата здания/направления приостанавливает работу. Можно передать её другому послушнику или отменить без возврата знаний. Общий репертуар хранится у дома. Послушники готовят личный набор из четырёх заклинаний в городе, заменяя выбранное прежнее; расход знаний на вторичную подготовку не взимается. Для совместимости исходные Болт, Лечение, Оберег и Проклятье остаются стартовым набором. Новые исследования: Крепкий оберег (+4 КБ), Пламя (+4 урона), Ледяной болт (замедление), Исцеление духа (18 ХП и −15 стресса), Похищение жизни (частичное лечение от нанесённого урона). Новые заклинания применяются по тем же правилам дальности, обзора, маны, бессознательного состояния и действий.

**Найм.** Плац, Стрельбище, Слесарная мастерская и Магическая академия дают +1 к обычному уровню кандидатов соответствующего класса. Повторы не суммируются, новые уровни не выдаются уже нанятым героям. Кандидаты сохраняют имена и черты; бонус пересчитывается при изменении построек. Наём обычных базовых классов доступен без этих зданий. Соответствие Слесарной мастерской плуту принято как временное решение для проверки.

**Производство.** Отдельная очередь использует городское производство. Изготавливаются оружие (+1 атаки), броня (+1 КБ), магический клинок, лечебные зелья и свитки известных заклинаний. Магические работы расходуют кристаллы. Каждое соседнее Место силы снижает цену на 1, минимум до 1 кристалла; удалённое Место силы не даёт скидку. Библиотека зачарований и Алхимическая лаборатория могут обработать существующее оружие/броню: вещь передаётся мастеру и возвращается на склад. На предмете одно свойство: дружественное заклинание даёт +1 КБ, Пламя +2 урона, другая атакующая магия +1 атаки. Работа ставится на паузу при утрате цеха; при отмене зарезервированная вещь возвращается, затраченные золото/кристаллы не возвращаются.

**Снаряжение и расходники.** Выдача и возврат вещей доступны героям в городе. Одно оружие и одна броня; заменяемая вещь возвращается на склад. До двух расходников. В походе доступны только взятые героем зелья и свитки. Зелье лечит самого пользователя за 1 ОД; свиток позволяет применить заклинание без маны даже воину, расходуется при успешном применении и завершает действия. Правила подъёма бессознательного героя сохраняются. Свободные исследования и производство добавлены в список решений конца хода с явным пропуском.

**Резервная копия.** «Копия игры» в верхней панели создаёт самостоятельный HTML из уже открытой игры в браузере. Он содержит код и изображения, но не партию из localStorage. Партию сохраняет отдельный «Экспорт». Это дополнительный путь при сбое скачивания артефактов, а не фоновая отправка на компьютер.

Все новые цены, доходы знаний, длительность, размер набора, рецепты и свойства — пробные параметры, а не окончательный баланс. Цель партии остаётся 1–2 часа; полноформатные игровые пробы ещё нужны. ИИ использует новые учебные постройки; его работа с новой промышленностью и репертуаром пока ограничена.

Диагностика сбоя среды вынесена в ENVIRONMENT_INCIDENT_2026-11-03.md. Точная причина отключения и ошибки скачивания не установлена.

## Новое в 0.7

**Поступки вместо календаря.** Удалены создание спора каждый третий ход и автоматическое исчезновение через два хода. Поступки вызывают взаимные реакции товарищей: сострадание одобряет помощь, осторожность опасается рискованной защиты, алчность возражает против подарков из казны, общительность одобряет переговоры. Подсказка варианта показывает реакции до решения. Одинаковый поступок засчитывается одной паре не чаще одного раза за ход. Последние причины изменений записаны в карточках обоих героев.

При неприязни от −2 конкретный поступок может вызвать спор. Одновременно у игрока один активный бытовой спор. Он доступен через список решений; его можно осознанно отложить. Через три хода игнорирования уже возникшего спора верность его участников снижается на 2 за ход. В городе это может компенсироваться обычным восстановлением верности. Разделение конфликтующих героев завершает текущий спор, сохраняя взаимную неприязнь и историю.

**Примирение.** Проверка выбранного героя: d20 + Мудрость (+3 от сострадания) против КС 12, +2 за каждого упрямого спорящего. Успех: отношения +2, верность +3 обоим. Неудача: отношения −1, спор остаётся; повторная проверка со следующего хода. Альтернатива — гарантированная компенсация 20 золота с теми же положительными эффектами. Поддержка одного закрывает спор с верностью +8 / −4 и отношениями −1. Любое решение стоит 1 очко перемещения.

**Спасение и прикрытие.** Подъём товарища без сознания даёт +2 взаимного доверия один раз на пару за бой; обычное лечение отношения не повышает. При доверии от +2 открывается прикрытие друга по команде игрока: 1 ОД, соседний живой друг, +2 ко всем КБ до начала следующего хода своей стороны, пока прикрывающий рядом и в строю. Одна активация на пару за бой. Стресс и согласованная ранее сдача остаются отдельной механикой.

**Соперничество.** Общая победа двух храбрых героев, каждый из которых попал по противнику, либо успех одного из двух общительных героев в переговорах может создать взаимное дружеское соперничество. Пока соперник в строю, герой получает +1 к урону. Алчный соперник может обидеться на премию другому. Соперничество само по себе не снижает доверие и не создаёт спор.

**Мир существ.** Добавлены восемь групп встреч: разбойники, волки, пауки, гоблины, кобольды, нежить, огры, дикие вепри; внутри групп 13 вариантов противников. Семейства распределяются по подходящим ландшафтам, присутствуют в логовах и засадах, угрожают деревням; часть руин охраняется пауками или нежитью. Огры встречаются в известных логовах, а не в случайных засадах. Существа стационарны в логовах, свободно бродящих отрядов пока нет.

Названия и повадки используют знакомые образы бестиариев D&D и Pathfinder 2e. Статистики и описания написаны для правил прототипа, это не полная реализация систем этих игр. Волки получают +2 к атаке при помощи стаи; попадания пауков замедляют движение; гоблины лучше используют укрытия; кобольды защищены от стрел; зомби медленные и живучие; скелеты имеют высокую колющую КБ; вепри получают +2 урона после движения; огры используют тяжёлые удары. Бестиарий и карточки логов объясняют угрозы. Для новых существ используются простые временные фигуры, отдельные художественные спрайты ещё не созданы.

**Сохранения и темп.** Формат сохранения 4 сохранён. Загрузчик выравнивает старые парные отношения и удаляет старые беспричинные календарные споры. Старым логовам и деревенским угрозам назначаются семейства; незавершённый старый бой сохраняет прежних противников. Ориентир партии — 1–2 часа; лимит пока 60 ходов, реальная длительность и баланс требуют игровых проб. Числовые бонусы, цены, частота логов и пороги отношений — временные параметры.

## Новое в 0.6

**Приказы и завершение хода.** Кнопка конца хода показывает список оставшихся важных решений: действия отрядов, доступная очередь строительства, расширение территории, доступный выбор подкласса в городе, готовая основная часть указа, конфликт и готовый штурм. Каждое решение нужно выполнить либо явно пропустить в этом ходу. Пропуск сохраняет ресурсы и очки движения, его можно отменить. После изменения ситуации пункт проверяется снова; все пропуски сбрасываются на следующем ходу. Отряд на сопровождении или в ожидании подготовки осады отдельного приказа не требует. Строительство проверяется только при наличии подходящего места и ресурсов. Найм, подарки, покупка благ и улучшение стен остаются добровольными.

**Начало хода.** Общая сводка появляется после завершения анимаций. В неё попадают ваши постройки и стены, прирост населения, указы и штрафы, новые споры, угрозы ухода героев, осады, результаты боёв за ход соперников, прибытия и происшествия с повозками. Казна указывается после дохода, жалованья и торговли. Из карточки можно перейти к нужному экрану; сводку можно повторно открыть у кнопки конца хода. Непрочитанная сводка и решения сохраняются в партии. Скрытые хозяйственные события чужих домов в сводку не включаются.

**Тактические ландшафты.** Поле 8×6 формируется из ландшафта мирового гекса: равнина, лес, холмы, горы, река или болото. Генерация детерминирована, места появления героев и обходные пути открыты. Деревья и скалы блокируют движение и обзор. Глубокая вода блокирует только движение. Кустарник и осыпи дают +2 КБ от стрел и магических атак с дистанции больше одного гекса. Грязь, осыпи, мелководье и возвышенности стоят 2 очка движения, топь — 3. Возвышенность даёт +1 к дальним атакам по целям ниже. Путь рассчитывается с учётом стоимости; герои идут по нему, обходя препятствия. ИИ использует те же правила движения и обзора. Числа стоимости и бонусов — параметры для тестирования.

**Подсказки.** Наведение на клетку объясняет её эффект и стоимость пути. Наведение или клавиатурный фокус на способности показывает цель, дальность, действие, стоимость и ограничения. Подсказка доступна и для неактивной способности.

**Живая карта.** В паузах между действиями качается трава и деревья, мельницы медленно вращают лопасти. Мельницы рисуются процедурно, остальные объекты используют встроенный атлас. Фон обновляется примерно 15 раз в секунду, рисуются только видимые в окне клетки. При открытии игровых окон или скрытии вкладки фон приостанавливается. Общая настройка отключения анимаций останавливает и ветер. Состояние партии и игровые броски от фоновой анимации не меняются.

Сохранения пересборки 0.4 и версий 0.5–0.5.1 совместимы. У старых сохранений боя ландшафт создаётся при открытии; занятые героями клетки очищаются от непроходимых препятствий.

## Исправления 0.5.1

Карта и поле боя рисуются в родном разрешении экрана с учётом devicePixelRatio. Подписи выводятся обычным шрифтом с минимальным размером 12 CSS-пикселей; увеличение низкого разрешения больше не размывает буквы. Пиксельные изображения сохраняют отключённое сглаживание.

Переход между соседними гексами длится 620 мс при скорости 1×. Во время движения ноги чередуют положение, корпус немного наклоняется; направление фигурки соответствует движению. Показ управляется существующими настройками анимации и пропуском.

## Анимации 0.5

- Плавное движение отрядов на карте и героев в бою, постепенное раскрытие тумана.
- Вращающийся кубик показывает фактический результат, модификатор и сложность. Попадание и урон показываются отдельно; критический урон получает дополнительный кубик. При преимуществе видны оба результата.
- Эффекты ударов, стрел, магии, лечения, защиты, проклятий, решимости и воскрешения; всплывающие значения урона и лечения.
- Строительные леса и ход работ в городе, эффекты начала и завершения строительства, расширения территории.
- Движение повозок, сопровождения и эффект прибытия.

Кнопка **«Анимации»** в верхней панели: скорость 1×/2×/4×, отключение, подробный автобой. По умолчанию автобой краткий. **Пробел** или **«Пропустить»** завершает показ, сохраняя результат действия. Во время показа повторные игровые команды заблокированы. Настройки сохраняются отдельно от партии; системное уменьшение движения учитывается при первом запуске.

Это процедурные анимации существующих пиксельных фигурок: перемещение, чередование положения ног, наклон корпуса, поворот, частицы и подсветка. Отдельного покадрового набора походки для каждого героя пока нет. Визуальная очередь не перебрасывает кубики и не меняет игровые правила.

## Запуск

Откройте `index.html` в современном браузере. Все изображения, стили и код встроены; интернет и WebGL не нужны.

Если локальные HTML запрещены браузером:

```sh
python -m http.server 8000
```

Откройте локальный адрес сервера. Автосохранение привязано к браузеру и адресу страницы. Для переноса партии используйте «Экспорт» и «Загрузить». Сохранения пересборки 0.4 совместимы с 0.5; более ранние исходные прототипы имеют другой формат.

**Для сохранения работы скачайте HTML и ZIP с исходниками.** Сборка не публикует среду, не отправляет код в GitHub и не меняет конфигурацию среды.

## Что пробовать

1. Выберите двух кандидатов первого уровня: классы и черты видны заранее.
2. В городе выберите здание и гекс. До оплаты показаны итоговый эффект и связи с непосредственными соседями.
3. Попробуйте Мастерскую рядом с Рынком и вдали от него. Затем замените Рынок Торговым подворьем: базовый доход сохраняется. На пустой клетке такая замена запрещена.
4. Дождитесь роста населения и присоедините одну клетку второго кольца. Доступно шесть начальных и двенадцать дополнительных строительных мест. Стены занимают границу территории, а не гекс.
5. Наймите новых героев. До четырёх в отряде; пятый создаёт новый отряд в городе. Героя можно отделить или передать в соседний отряд со свободным местом.
6. Найдите деревню. В событии выберите участвующего героя; черты и характеристики влияют на бросок. Выполните просьбу и развивайте торговлю.
7. Выполните обязательную часть королевского указа. Дополнение необязательно. Репутацию можно потратить на блага короля.
8. В бою попробуйте лечение упавшего: он получает одно действие. Победивший отряд приводит своих упавших в чувство с одним здоровьем.
9. После победы над другим вассалом распределите тела и сдавшихся. Победитель забирает все вещи. Для пленников нужна Тюрьма без ограничения вместимости.
10. Отправьте повозку с останками или пленником. Маршрут и примерный срок видны заранее. Сопровождение идёт вместе с повозкой; неохраняемый груз можно перехватить.
11. Храм восстановления строится поверх Святилища. Для воскрешения требуется доставленное тело. Без Верховного жреца герой теряет уровень и получает слабость; героя первого уровня воскресить нельзя. С Верховным жрецом в городе уровень сохраняется, слабость меньше.
12. Осадите вражескую столицу. Стены дают защитнику время на возвращение или вылазку. Проигранная вылазка означает захват города. Уход осаждающих снимает осаду без сохранения повреждений.

## Управление и размещение интерфейса

Карта занимает основную часть экрана. Ресурсы расположены сверху; разделы — слева; выбранный гекс и действия — справа; отряды и герои — снизу; завершение хода — справа внизу. Это размещение по принципу Age of Wonders, без воспроизведения её графических материалов.

Щелчок выбирает гекс, «Идти сюда» отправляет отряд. Перетаскивание сдвигает карту, колесо меняет масштаб. Стрелки также сдвигают карту. Есть кнопки масштаба, поиска выбранного отряда и обзора всей карты. Сетка переключается отдельно.

В бою выберите героя, затем клетку или цель. Два действия на раунд; движение стоит одно действие, обычная атака завершает действия героя. Стриж может атаковать дважды. Заклинания Послушника: Болт, Лечение, Оберег, Проклятье. Медитация возвращает ману. Физические умения — раз за бой. Автобой использует тот же механизм.

## Реализованные правила

- Четыре вассала; один человек, три компьютерных соперника. Одна столица у каждого. Новых городов и форпостов нет.
- Несколько отдельных отрядов, не более четырёх героев. Соседние отряды не присоединяются к бою.
- Базовые классы нанимаются без специальных зданий. Подклассы открываются зданиями; разрушение здания не отнимает подкласс у обученного героя.
- Выбор подкласса с пятого уровня сразу даёт его первую способность.
- Верность, черты, события, отношения внутри отряда. Длительно неразрешённый конфликт снижает верность. Низкая верность вызывает предупреждение, затем уход.
- Стресс от критических попаданий, некоторых способностей, гибели товарищей и боя с бывшими товарищами. На пределе — проверка решимости: редкое воодушевление или сдача.
- Все вещи проигравших получает победитель. Пленник возвращается без вещей. Тела остаются на карте, пока их не отправили повозкой.
- Повозки с телами, пленниками и освобождёнными героями: маршрут, сопровождение, задержки, нападения, перехват и спасение.
- Воскрешение собственных и чужих героев. Чужой герой возвращается с низкой верностью.
- Синергии зданий только между непосредственными соседями. Нет числовых уровней зданий: конкретные замены поверх требуемого предшественника сохраняют его эффекты.
- Рост населения открывает второй круг территории. Показатели роста и производства видны только в городе.
- Один королевский указ: обязательная основа для каждого и дополнительные условия. Штраф только за провал основы. Особый артефакт может исполнить обе части одновременно.
- Репутация за указы, торговлю, просьбы деревень, подарки и результаты битв. Боевые очки учитывают исходное соотношение сил. Блага расходуют текущую репутацию.
- Деревня торгует с несколькими вассалами, но особая дружба принадлежит одному.
- Осада на глобальной карте, блокада торговли, вылазка, сброс прогресса при уходе. Потеря столицы — немедленное поражение.

## Пробные параметры и ограничения

Список зданий временный и подписан в интерфейсе. Его можно заменить вашим списком. Цены, длительности, эффекты соседства, темп роста, формулы репутации и стресса требуют игровых проб.

Для проверки использованы уровни 1–8. Верховный жрец временно доступен Жрецу восьмого уровня при Соборе света; точный уровень дальнейших специализаций ранее не был утверждён. Воскрешение стоит 25 золота и 5 кристаллов; слабость длится 4 хода без Верховного жреца и 2 с ним, уменьшается от соответствующей синергии.

Вещи пока представлены списком оружия и артефактов. Полная система слотов, визуальная смена экипировки, полное древо талантов, Кража Вора и все продвинутые подклассы пока не реализованы. Подклассы имеют пробные боевые эффекты. Отряд выбирает один обоз для сопровождения. Стоимость выкупа в этой пробе фиксируется уровнем пленника; полноценный торг не реализован. Сетевая игра не добавлена.

Столицы отодвинуты от края карты на два гекса, чтобы второе кольцо содержало все двенадцать мест. Городские постройки на экране строительства отображаются схемой с названиями, значками и линиями бонусов; отдельные изображения всех зданий пока не нарисованы.

Условия победы для пробы: не менее 60 репутации и отрыв минимум 40 на протяжении трёх полных ходов; лидерство после 60 ходов; либо захват всех остальных столиц. При равенстве в конце партии — ничья.

## Файлы и воспроизводимость

- `template.html` — интерфейс и стили.
- `src/game.js` — логика, состояние, интерфейс действий.
- `src/development.js` — здания, исследования, производство, обучение и снаряжение.
- `src/relations.js` — взаимные отношения, причины споров, примирение, спасение и соперничество.
- `src/bestiary.js` — существа, распределение по ландшафтам, группы встреч и особенности.
- `src/turns.js` — проверка решений, отложенные приказы и сводки хода.
- `src/tactics.js` — ландшафты боя, обзор, укрытия и поиск пути.
- `src/tooltips.js` — всплывающие объяснения способностей.
- `src/animations.js` — визуальная очередь, кубики, эффекты и настройки.
- `src/painter.js` — пиксельная карта и поле боя.
- `assets/atlas.png`, `assets/atlas.json` — созданные для пересборки объекты и их координаты.
- `tools/build.py` — автономная сборка HTML без сети и зависимостей.
- `tests/test_game.py` — браузерные игровые сценарии.
- `tests/test_animations.py` — анимации, пропуск, настройки, соответствие игровым результатам.
- `tests/test_rendering.py` — выбор гексов и движение в бою при масштабе экрана 100%, 125% и 200%.
- `AGREED_RULES.md` — зафиксированные решения из переписки.
- `reference/` — повторно полученные исходные приложения пользователя (RAR и DOCX), сохранённые как материалы проекта.

```sh
python tools/build.py
python tests/test_game.py
python tests/test_animations.py
python tests/test_rendering.py
python tests/test_turns_and_tactics.py
python tests/test_relations_and_bestiary.py
python tests/test_development.py
python tests/test_battle_lab.py
```

Для игры Python не требуется. Для тестов нужны Python Playwright и Chromium; путь задаётся через `CHROMIUM_PATH` при необходимости. Тест сам поднимает временный локальный сервер. Для воспроизведения сценариев в браузерной консоли доступен `window.Game`.

## Выдача резервных копий через браузер

`tools/build_backup_page.py ARCHIVE.zip OUTPUT.html --version 0.7` создаёт страницу со встроенным ZIP. Её кнопка скачивания формирует Blob в браузере и не использует серверную кнопку загрузки артефакта.

В поддерживаемом Chrome доступен выбор папки. Пользователь может явно включить сохранение новых версий при открытии страницы выдачи. Папка хранится в IndexedDB; автоматическая запись происходит только при сохранённом разрешении браузера. Иначе нужен повторный выбор или подтверждение. Отдельные окна предпросмотра могут блокировать выбор папки и загрузки. Есть запасной способ через Base64.

Это сохранение при открытии обновлённой страницы, а не фоновая доставка на компьютер. Закрытая страница не следит за новыми сборками. При новом адресе/профиле или очистке браузера разрешение может потребоваться снова. Для каждой новой версии нужно заново собрать ZIP и страницу выдачи.
