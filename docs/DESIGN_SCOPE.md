# Диздок 1.0 — рамки первой полной версии

Решения из ответов пользователя в начале этапа 01, после прототипа 0.8.8. Это утверждённые направления; оставшиеся вопросы перечислены отдельно. Файл дополняет AGREED_RULES.md. Предложения помощника не становятся принятыми без ответа пользователя.

## Принято

| Решение | Содержание | Что это означает для разработки |
|---|---|---|
| Платформа | Приложение для ПК | Браузер — временный инструмент проверки механик. Окончательная ОС и движок ещё не выбраны. |
| Первая версия | Одиночная игра против ИИ | Онлайн и локальная игра нескольких людей не входят в начальный режим. Их добавление позже не решено. |
| Боевая основа | Текущая новая модель боя подходит; возможны небольшие изменения | ОД, движение, типы защиты, уворот, криты и барьер — рабочая основа дизайна. Числа, баланс, детали и способности можно корректировать. |
| Объём | Обсуждаемые основные системы планируются в первую версию без предложенного сокращения | Город, деревни, указы, исследование, классы/подклассы, отношения, верность, стресс, осады, плен, перевозка, воскрешение, производство и исследования сохраняются в плане. Конкретные каталоги контента ещё нужно заполнить. |
| Отряд героев | Не более четырёх героев | У вассалов отряды по четыре; объединение нескольких отрядов в одном бою по-прежнему исключено. |
| Монстры | Не более двенадцати монстров одновременно в стычке | Число существ может превышать четыре: слабые скелеты и подобные враги могут встречаться более многочисленной группой. Лимит относится к одновременному присутствию, а не общему числу за весь бой. |
| Глобальные ходы | Сначала игрок, затем ИИ по очереди | После действий всех вассалов начинается следующий общий раунд. Это правило начальной одиночной версии. |
| Длительность | Несколько вариантов длительности при старте | Три режима: короткая, стандартная, длинная. Различаются лимитом общих раундов и скоростью развития. Целевое реальное время: короткая 1–2 ч, стандартная 3–5 ч, длинная 6–10 ч. Скорости систем балансируются индивидуально (строительство, исследования, ресурсы, опыт, указы и события), а не единым множителем. Конкретные лимиты и коэффициенты ещё не согласованы. |
| Досрочная победа по репутации | Условие нужно удерживать; пробная длительность — 5 ходов | В контексте принятого предложения речь об общих глобальных раундах. Порог зависит от выбранной длительности партии; численные значения ещё не выбраны. После выполнения условий в конце общего раунда отсчёт начинается только со следующего общего раунда. Для запуска необходимы достижение порога и единоличное лидерство. Проверка в конце общего раунда; при утрате любого условия счётчик полностью сбрасывается, в том числе после расхода репутации, если расход нарушил условие. Число 5 экспериментальное. |
| Доступность развития | Все основные системы доступны и в короткой партии; игрок выбирает специализации | Короткий режим не должен принуждать к единственному пути развития, но развить всё за одну партию не требуется. |
| Захват столицы | Поражение владельца немедленно после успешного штурма | Удерживать захваченную столицу дополнительные раунды не нужно. Если устранён последний соперник, военная победа наступает немедленно. |
| Немедленная военная победа | Устранение последнего соперника завершает партию в момент события | Не требуется ждать конца общего раунда. Успешное завершение штурма — момент устранения владельца; исключительные случаи ещё уточняются. |
| Равная репутация к концу срока | Пробно — ничья | Это равенство лидеров при достижении лимита партии; другие одновременные исходы пока не определены. |

Предел 12 не увеличивает размер отряда героев. Предложенное помощником распределение частоты встреч «4–6 / 7–8 / 9–12» пользователем отдельно не утверждено; сохранять его только как идею для балансировки. Учёт призывов и смешанных составов требует отдельного уточнения.

## Что уже согласовано ранее

Одно королевство, четыре соперничающих вассала, по одной столице, без основания новых городов/форпостов. Стартовый отряд — два выбранных героя первого уровня; отрядов может быть несколько. Партия ориентирована на 1–2 часа. Пиксельный формат. Победа связана с репутацией к концу срока, достижением большого значения/превосходства либо устранением соперников. Потеря столицы означает поражение. Успешный штурм столицы немедленно устраняет владельца; остальные спорные исходы ещё требуют фиксации.

## Следующие решения этапа 01

1. Численные пороги репутации для трёх длительностей, уведомления соперников и детали отсчёта при восстановлении условия.
2. Конкретные лимиты глобальных раундов и индивидуальные параметры темпа для трёх режимов; проверка достижимости разных специализаций.
3. Особые случаи при нескольких условиях победы, включая проверку репутации на последнем раунде.
4. Порядок общих событий и проверки победы; одновременные условия победы, не охваченные ничьей по итоговой репутации.
5. Уточнение поддерживаемых ОС, стартового выбора вассала и границ каталогов контента.
6. При переходе к бою: призванные существа в лимите 12, смешанные группы, подкрепления и их условия появления.

## Статус реализации

Прототип 0.8.8 остаётся браузерным. В нём кампания и новая боевая лаборатория используют разные системы. Принятие боевой модели за основу не означает, что перенос в кампанию уже выполнен. Лабораторные паки пока состоят из четырёх противников; бой с количеством до 12 монстров ещё нужно реализовать, включая расстановку, интерфейс и ИИ. Этот ответ пользователя зафиксирован как дизайнерское решение, а не объявление готовой функции.

Порядок ходов, варианты длины партии с изменением скорости развития, пятиходовое удержание с порогом и единоличным лидерством, проверкой в конце раунда и полным сбросом, а также ничья выше зафиксированы как решения диздока. Соответствие прототипа этим правилам ещё необходимо проверить при реализации; параметры текущего кода не заменяют принятую спецификацию.
