# Звук и музыка

## Микшер
Master суммирует Music, SFX, UI и Ambience. В настройках пять независимо сохраняемых уровней. Нулевое положение выключает шину, остальные значения переводятся из линейной громкости в dB. Меню, настройки и справочник сохраняют позицию общей темы при переходах. При первом входе громкость плавно возрастает. При добавлении музыки карты, города и боя нужны переходы между разными темами. Скорость анимаций влияет только на представление.

## Первая сессия
Оригинальная инструментальная тема меню с лютневым щипком и протяжными нижними голосами зациклена на 23,04 секунды. Для кнопок написан отдельный короткий сигнал. При прослушивании в настройках он направляется в выбранную шину. Файлы, авторство и условия использования перечислены в assets/LICENSES.md.

## План по сценам
| Этап | Музыка и окружение | Сигналы действий |
|---|---|---|
| 1 | Витрина с ручным просмотром поз | Метки контакта стопы и оружия для будущих звуков |
| 2 | Боевая петля, победа, поражение | Шаги, удар, промах, блок, семь школ магии, лечение, падение |
| 3 | Простор карты, ветер, лес, вода | Кубик d20 на столе только вне боя |
| 4 | Городская тема, городской фон | Стройка, завершение проекта, монеты |
| 6–7 | Тема меню и переходы по состояниям | Полный набор интерфейса, уровни, проверка совместного воспроизведения |

Для недостающих музыкальных тем допустимы две дорожки производства: оригинальная камерная партитура с общим мотивом меню или заказ композитору с письменными правами на встраивание и распространение исходников. Для недостающих звуков — собственная обработанная запись либо индивидуально проверенная запись CC0/CC-BY с оригинальной страницей и обязательной атрибуцией. Один файл — одна запись в реестре. До проверки прав файл не входит в игру. Набор сцены, длительность перехода, громкость и одновременные звуки проверять в настоящем игровом действии, включая победу и поражение.
